== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/nextgen-languages-evangeliser.git
cd nextgen-languages-evangeliser
just build-release
----

Output: `{{BUILD_OUTPUT_PATH}}`

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Nix

[source,bash]
----
nix build
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t nextgen-languages-evangeliser .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/nextgen-language-evangeliser/`
| Data files, assets

| `$PREFIX/share/doc/nextgen-language-evangeliser/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/nextgen-language-evangeliser/config.toml`

Fallback: `$HOME/.config/nextgen-language-evangeliser/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just run --version   # Version check
just run --selftest  # Built-in self-test
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update nextgen-language-evangeliser`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/nextgen-language-evangeliser-instance1 --config=/etc/nextgen-language-evangeliser/instance1.toml
just install --prefix=/opt/nextgen-language-evangeliser-instance2 --config=/etc/nextgen-language-evangeliser/instance2.toml
----

Each instance has isolated config, data, and logs.
